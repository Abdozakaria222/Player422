# Player 422

مشغل بث مباشر لريسيفرات وبوكسات الأندرويد. بيفك الصورة **Software** دايماً (FFmpeg)، علشان قنوات الـ 4:2:2 تشتغل على الأجهزة اللي الـ Hardware decoder بتاعها مش بيدعمها.

## البناء
1. ارفع الفولدر ده على ريبو جديد في GitHub.
2. هيشتغل Actions ← **Build APK** لوحده (أو شغله يدوي من Run workflow).
3. حمّل الـ APK من Artifacts ← `Player422-APK` ونزّله على الريسيفر.

## الاستخدام
- **أول مرة:** حط رابط القناة أو رابط قائمة m3u وفعّل "تشغيل تلقائي مع فتح الريسيفر".
- بعد كده: أول ما تفتح التطبيق (أو الريسيفر يفتح) بيشغل آخر قناة كنت عليها تلقائي.
- **كمشغل خارجي:** في أي تطبيق IPTV اختار External player ← Player 422، والقناة هتشتغل فيه على طول.

## الريموت
| الزرار | الوظيفة |
|---|---|
| فوق / تحت (أو CH+ / CH-) | القناة اللي بعدها / اللي قبلها |
| OK | قايمة القنوات |
| يمين / INFO | بيانات القناة |
| شمال / MENU | الإعدادات |
| 1–9 | الانتقال لرقم القناة |

## ملاحظات
- قنوات MPEG-2 بصيغة 4:2:2 خفيفة. أما H.264 بصيغة 4:2:2 بدقة 1080i فممكن تقطّع على المعالجات الضعيفة. لو حصل كده جرّب تقفل Deinterlace.
- لو الانقطاع حصل، المشغل بيعيد المحاولة لوحده.
